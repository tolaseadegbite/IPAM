# Search

Three layers, fastest first.

## Command palette

Press the palette button (or its keyboard shortcut) anywhere and type: jump to pages (`Go to…`), create records (`New…`), or run actions like **Scan now**. It also live-searches devices, subnets, branches, departments, employees, IPs, and cards — cards jump to their parent board. Shortcuts to remember:

- Employees, Boards, IP Addresses, Dashboard each have a `Ctrl+Shift+<letter>` jump (shown in the palette footer)
- `↑↓` navigate, `↵` open, `esc` close

## Global search

The header search runs one query across devices, IPs, and people (full-text, 50 best hits). Use it when you know a name, address, or fragment but not where it lives.

## Per-page filters

Every index page (devices, IPs, employees, …) has its own filter panel: type-ahead fields, dropdowns, and saved shortcuts. Two are pinned in the sidebar:

- **Rogue Devices**: IPs answering ping with no device attached
- **Critical Devices**: devices flagged critical

Filters compose — combine type, status, department, and branch to slice the inventory. Dismissible pills above each list show what's active.
